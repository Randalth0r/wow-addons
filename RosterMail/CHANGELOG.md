# Changelog

All notable changes to RosterMail are documented in this file.

## [1.0.0] - 2026-08-01

Initial stable release. First official CurseForge-ready build of RosterMail.

## [0.1.0-beta1]

### Added
- Dynamic mailbox side panel listing realm alts with class-colored names, level/class text, and faction icons
- Per-row delete button (trash/remove control) to drop a character from the saved roster
- Profession icon capture and display for allowed primary professions
- Dynamic roster refresh after deletes and when the mail UI opens

### Fixed
- Profession tooltip scope/closure bug that could show the wrong profession name
- Text and faction icon alignment on roster rows
