# Changelog

## 1.0.0 — 2026-08-09

First public release.

- Text panel for character stats (up to 6 at once)
- Layouts: One per Row / Single Row
- Colored labels with swatches in the config panel
- Lock the panel — gear hides while locked, lock stays on the right
- Background on/off from config
- Font size control (8–20), default 11 on a fresh install
- Single Row scales width and height with the font so the box stays proportional
- In combat, holds the last readable values when Blizzard secrets the live ones (12.0+)
- Slash: `/ps`, `/powerstats`
- Retail interfaces `120007` and `120100`
